# Aura Protocols — Project Context

## What This Is
A Next.js 16 **retail storefront** for research peptides (Aura Protocols LLC sells its own lot-tested compounds). Formerly an affiliate index — all vendor affiliate links were removed in the 2026-09-27 retail redesign. Old `/go/*` links 301 to our own product pages.

Live at **https://auraprotocols.com** (Vercel project `aura-protocols`; PAUSED until checkout ships). `shop.auraprotocols.com` 301s to the apex.

## Stack
- Next.js 16 (App Router), React 19, TypeScript, Tailwind v4
- Supabase **Aura Store** — Auth (customer accounts, `@supabase/ssr`) + tables: `gate_attestations`, `subscribers`, `inquiries` (`apps/shop/supabase/storefront.sql`); `customers`, `account_agreements`, `orders`, `order_items`, `stripe_events` (`accounts-checkout.sql`); `account-gate.sql` (customers verify/opt-in columns, `orders.new_account_discount`, `gate_lookups`, `account_id_by_email()`); partner tables in `partners.sql` (partners, aliases, clicks, commissions, adjustments, payout runs/payouts, store-credit ledger; private `w9` bucket); discount codes in `discount-codes.sql` (`discount_codes`, `discount_batches`, `code_redemptions`, `discount_code_events`, `code_attempts`, `shop_settings`; `claim_discount_code` + settle trigger on order status). RLS on, no policies: service role, server only. Supabase **Confirm email is OFF** — our own verification (`lib/account/verify.ts`, `/auth/verify`).
- Stripe hosted Checkout via `lib/commerce.ts` (card, wallets, ACH; Stripe Tax); webhook `app/api/stripe/webhook` → `lib/stripe-events.ts`; daily reconcile cron `api/cron/reconcile` (missed paid webhooks, expired sessions, orphaned pending orders). Payment methods are set in the Stripe dashboard, not code (runbook in the private repo).
- Amazon SES for email; bounces/complaints arrive via SNS → `api/ses/events`; vitest + Testing Library
- Partner program: `lib/partners/*` (pure rules: codes, tiers, discounts, payout-math; data: `data.ts`, `ledger.ts`), tables in `apps/shop/supabase/partners.sql`, `/affiliates` (program + calculator), `/partners` (dashboard), `/admin/partners`, `/admin/payouts`, daily cron `api/cron/partners-daily` (clears commission; payouts on the 1st/15th).

## Design System — "Pharmacopoeia" + storefront
- Scope class `.pharmacopoeia` (see `globals.css`). Tokens: paper `#EDE9E0`, paper-deep `#E2DCCC`, ink `#1C1A15`, ink-soft `#4A4438`, specimen `#A32B1F`, line `#C9C2AE`.
- Type: Newsreader display (`--font-newsreader`, italic accent word in specimen), Georgia body, JetBrains Mono micro-labels (`--font-jetbrains`, class `.s-micro`).
- **Square corners, 1px hairlines.** Storefront classes are prefixed `s-` and were ported from the approved mocks in the private repo (`docs/superpowers/specs/2026-09-27-storefront-mocks/`). Port from mocks — never freestyle UI.
- Brand: `AuraLockup` (animated pulse-line A). Vial label art: `components/store/Vial.tsx`.

## Compliance rules (enforced)
- Research use only. No dosing, protocols, reconstitution, benefits, "studied for", or human-outcome language anywhere. Scientific names only; chemical-class categories; no "stack".
- `pnpm --filter @aura/shop build` runs `scripts/compliance-scan.mjs` and FAILS on banned phrases. Fix copy, don't widen the allowlist.
- Account gate: browsing needs an account; the sign-up agreement (21+, RUO, dispute policy) is recorded in `account_agreements` (`gate_attestations` kept for history). The gate fails closed (a failed status check shows it).
- Before unpausing Vercel: `RELEASE_CHECK=1 pnpm --filter @aura/shop test` must pass (no placeholder prices/lots).

## Conventions
- **Relative imports only** in anything reachable from `next.config.ts` (`data/catalog*.ts`, `lib/catalog.ts`, `lib/redirects.ts`, `lib/constants.ts`). Always verify with a real `next build`.
- `BASE_URL` = `https://auraprotocols.com` in `layout.tsx`, `sitemap.ts`, `robots.ts` — keep in sync.
- New static pages must be added to `sitemap.ts`. Legal pages are linked from `SiteFooter` only.
- Checkout goes through `lib/commerce.ts` (`CommerceAdapter`). Starting a checkout closes the customer's earlier unfinished ones (expires the Stripe page, cancels the order; the cancel trigger returns held store credit).
- Authorization lives in `lib/dal.ts` (`requireCustomer`, `requireOwner`, `requirePartner`, `requireApprovedPartner`) — call it next to every data access. `proxy.ts` refreshes sessions and, for `?ref=`, sets the signed `aura_ref` cookie and counts the click; it does no authorization.
- Order status changes go through `transitionOrder` (`lib/orders.ts`) and the machine in `lib/order-status.ts` — never update `status` directly.
- Prices are rebuilt server-side by `lib/pricing.ts`; never trust cart prices from the browser.
- Discounts go through `lib/discounts/engine.ts` only: per item the larger of pack, partner/new-account percent or an item-% code → an order code (replaces the item discounts if cheaper, or applies on top) → the store-wide cap (`shop_settings.max_discount_pct`, 30, editable 15–60) → free shipping. `orders.partner_discount_cents` = every discount beyond pack price (commission base stays goods paid); `orders.code_discount_cents` = the code's share. One code box per order; admin codes share one namespace with partner codes. Code uses are claimed with the pending order (`claim_discount_code`) and settled by the order-status trigger — never update `code_redemptions.state` directly except the owner's reset. Store credit is a payment, not a discount — tax is pre-computed with Stripe Tax before credit applies.
- Commission changes only through `lib/partners/ledger.ts` (created on payment, clearing on ship, reversed on refund/chargeback). Partner bank/Zelle details are AES-GCM encrypted (`PAYOUT_DETAILS_KEY`).
- Failures must be loud: a write that can fail throws (or alerts the owner via `alertOwner`), never reports success; webhook handlers throw to get a Stripe retry when an order isn't matched yet.
- New-account offer: 15% off a first order within 3 days of sign-up (NEW_ACCOUNT_DAYS), automatic (`lib/account/offer.ts`); larger-of with pack; beats a partner code but the partner keeps commission.
