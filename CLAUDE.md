# Aura Protocols — Project Context

## What This Is
A Next.js 16 **retail storefront** for research peptides (Aura Protocols LLC sells its own lot-tested compounds). Formerly an affiliate index — all vendor affiliate links were removed in the 2026-09-27 retail redesign. Old `/go/*` links 301 to our own product pages.

Live at **https://auraprotocols.com** (Vercel project `aura-protocols`; PAUSED until checkout ships). `shop.auraprotocols.com` 301s to the apex.

## Stack
- Next.js 16 (App Router), React 19, TypeScript, Tailwind v4
- Supabase (service role, server only) — `gate_attestations`, `subscribers`, `inquiries` (`apps/shop/supabase/storefront.sql`)
- Amazon SES for email; vitest + Testing Library

## Design System — "Pharmacopoeia" + storefront
- Scope class `.pharmacopoeia` (see `globals.css`). Tokens: paper `#EDE9E0`, paper-deep `#E2DCCC`, ink `#1C1A15`, ink-soft `#4A4438`, specimen `#A32B1F`, line `#C9C2AE`.
- Type: Newsreader display (`--font-newsreader`, italic accent word in specimen), Georgia body, JetBrains Mono micro-labels (`--font-jetbrains`, class `.s-micro`).
- **Square corners, 1px hairlines.** Storefront classes are prefixed `s-` and were ported from the approved mocks in the private repo (`docs/superpowers/specs/2026-09-27-storefront-mocks/`). Port from mocks — never freestyle UI.
- Brand: `AuraLockup` (animated pulse-line A). Vial label art: `components/store/Vial.tsx`.

## Compliance rules (enforced)
- Research use only. No dosing, protocols, reconstitution, benefits, "studied for", or human-outcome language anywhere. Scientific names only; chemical-class categories; no "stack".
- `pnpm --filter @aura/shop build` runs `scripts/compliance-scan.mjs` and FAILS on banned phrases. Fix copy, don't widen the allowlist.
- Entry gate (21+, RUO, dispute policy, email) logs every entry to `gate_attestations`; it fails closed.
- Before unpausing Vercel: `RELEASE_CHECK=1 pnpm --filter @aura/shop test` must pass (no placeholder prices/lots).

## Conventions
- **Relative imports only** in anything reachable from `next.config.ts` (`data/catalog*.ts`, `lib/catalog.ts`, `lib/redirects.ts`, `lib/constants.ts`). Always verify with a real `next build`.
- `BASE_URL` = `https://auraprotocols.com` in `layout.tsx`, `sitemap.ts`, `robots.ts` — keep in sync.
- New static pages must be added to `sitemap.ts`. Legal pages are linked from `SiteFooter` only.
- Checkout goes through `lib/commerce.ts` (`CommerceAdapter`); payments are a separate spec.
